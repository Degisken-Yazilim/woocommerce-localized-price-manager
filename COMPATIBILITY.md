# Compatibility

Localized Price Manager localizes the prices of simple products. Other product types are not localized.

## Supported versions

| Software | Supported range |
|---|---|
| PHP | 8.2 and newer |
| WordPress | 6.2 to 7.1 |
| WooCommerce | 7.9 to 11.2 |

## Page caching

Full-page caches (caching plugins, host page caches, CDN page caches) are not supported unless the shop pages are excluded from caching or the cache varies by country.
